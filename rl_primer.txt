Reinforcement learning (RL) is a branch of machine learning where an agent learns to make decisions by interacting with an environment and receiving feedback in the form of rewards. Unlike supervised learning, where a model learns from a fixed dataset of labeled examples, an RL agent learns through trial and error: it takes actions, observes the outcome, and gradually improves its behavior based on which actions led to good or bad results. This trial-and-error loop is what makes RL suited to problems like game playing and robotics, where the "correct answer" for any given situation isn't known in advance and must be discovered through experience.

The core building blocks of RL are the agent and the environment. The agent is the decision-maker: it observes the current state of the world, chooses an action, and receives feedback. The environment is everything the agent interacts with and has no direct control over; it responds to the agent's actions by transitioning to a new state and producing a reward. This back-and-forth between agent and environment repeats over time, forming a sequence of states, actions, and rewards called a trajectory or episode. An episode typically ends when some terminal condition is reached, such as winning or losing a game.

A reward is a single number the environment gives the agent after each action, signaling how good or bad that action was in that moment. The agent's entire goal is to maximize its cumulative reward over time, not just the reward from any single step. Because of this, RL problems often distinguish between immediate reward and return, where return is the total accumulated reward from a point in time onward, usually adjusted by a discount factor (a number between 0 and 1) that makes future rewards count slightly less than immediate ones. A discount factor close to 0 makes the agent short-sighted, caring mostly about immediate reward; a discount factor close to 1 makes it far-sighted, willing to sacrifice short-term reward for a better long-term outcome.

A policy is the agent's strategy: a function that maps states to actions, describing what the agent will do in any given situation. Policies can be deterministic (always picking the same action in a given state) or stochastic (picking actions according to a probability distribution). The entire point of an RL algorithm is to find a good policy, ideally an optimal one that maximizes expected return over time. Early in training, an agent's policy is usually close to random, since it hasn't learned anything yet; a successful training process gradually shifts the policy toward better and better decisions as the agent accumulates experience.

One of the central tensions in reinforcement learning is the exploration versus exploitation tradeoff. Exploitation means the agent takes the action it currently believes is best, based on what it has learned so far, in order to earn the highest reward it can right now. Exploration means the agent deliberately tries an action it's less certain about, in order to gather more information that might reveal an even better strategy later. An agent that only exploits risks getting stuck with a mediocre policy, having never discovered a better one. An agent that only explores never actually uses what it's learned to earn a good reward. Balancing these two is a foundational challenge in RL, and many algorithms include an explicit mechanism (such as occasionally taking a random action) to keep some exploration alive throughout training.

Formally, many RL problems are modeled as a Markov Decision Process, or MDP. An MDP is defined by a set of states, a set of actions, a transition function describing the probability of moving from one state to another given an action, and a reward function. The "Markov" part refers to the Markov property: the assumption that the next state depends only on the current state and action, not on the full history of everything that happened before. This assumption is what makes the math of RL tractable, since the agent doesn't need to remember an entire history, only where it currently is.

A value function estimates how good it is for the agent to be in a particular state, or to take a particular action in a particular state, in terms of expected future return. The state-value function, often written V(s), estimates the expected return starting from state s and following the current policy from then on. The action-value function, often written Q(s, a), estimates the expected return of taking action a in state s and then following the policy afterward. Q-values in particular are central to many RL algorithms, since if an agent knows the Q-value of every action in a given state, choosing the best action is as simple as picking the one with the highest Q-value.

Q-learning is one of the most well-known RL algorithms, and it works by learning Q-values directly through experience, without needing a model of how the environment behaves. After each action, the agent updates its estimate of Q(s, a) based on the reward it actually received plus its current estimate of the best possible future value from the next state. Over many episodes, these updates gradually converge toward accurate Q-values, at which point the agent can act near-optimally simply by always choosing the action with the highest estimated Q-value in any given state. Q-learning is called an off-policy algorithm because it can learn the optimal Q-values even while the agent is behaving somewhat randomly during exploration.

Policy gradient methods take a different approach from Q-learning: instead of learning value estimates and deriving a policy from them indirectly, they adjust the policy itself directly, nudging its parameters in the direction that increases the probability of actions that led to higher rewards. This is especially useful in environments with continuous or very large action spaces, where explicitly comparing Q-values for every possible action isn't practical. Policy gradient methods tend to be more computationally expensive and can be less sample-efficient than value-based methods like Q-learning, but they scale better to complex, high-dimensional problems, which is part of why they became central to modern deep reinforcement learning.

Deep reinforcement learning combines RL with deep neural networks, using a network to approximate the policy, the value function, or both, instead of tracking exact values for every possible state individually. This matters because many real-world problems have far too many possible states to track directly, such as every possible arrangement of pixels on a video game screen. Deep RL has been behind some of the most well-known achievements in AI, including agents that learned to play Atari games directly from raw pixels, and systems that learned to play complex games like Go and chess at a superhuman level through self-play, gradually improving their policy by playing millions of games against themselves.
